샌드백 사운드 채팅창 사용 가이드 (최종본)
0. 사전 필수 준비 (가장 중요!)
이 채팅창은 서버를 기반으로 작동하기 때문에 Node.js라는 프로그램이 반드시 깔려 있어야 합니다.

Node.js 공식 홈페이지에 접속합니다.

LTS 버전(가장 안정적인 버전)을 다운로드하여 설치합니다.

설치가 끝난 후 컴퓨터를 한 번 재부팅하는 것을 권장합니다.

1. 파일 구성 확인
폴더 안에 아래 파일들이 모두 들어있는지 확인하세요.

샌드백 채팅창.html: OBS에 띄울 화면 파일입니다.

duck_server.js: 채팅을 연결해주는 서버 엔진입니다.

서버시작.bat: 더블 클릭 한 번으로 모든 명령어를 실행해 주는 마법의 파일입니다.

음성파일 폴더: 명령어 전용 mp3들이 들어있는 저장소입니다.

package.json: 서버 실행에 필요한 설정 파일입니다.

2. 방송 시작 전 세팅 (딱 한 번만)
폴더 안의 **서버시작.bat**를 실행합니다.

처음 실행하면 필요한 패키지들을 자동으로 설치하느라 시간이 조금 걸릴 수 있습니다.

검은 창에 "샌드백 서버를 시작합니다..." 혹은 서버가 켜졌다는 문구가 나오면 준비 끝!

주의: 방송하는 동안 이 검은 창을 절대 끄지 마세요!

3. OBS에 적용하기
OBS [소스 목록] -> + 클릭 -> [브라우저] 추가.

[로컬 파일] 체크 후, 샌드백 채팅창.html을 불러옵니다.

사운드 활성화 (필수!):

소스 목록에서 '샌드백 채팅창' 우클릭 -> [상호작용] 클릭.

창이 뜨면 채팅창 화면 아무 데나 마우스로 꾹 클릭합니다.

(브라우저는 보안상 클릭을 한 번 해줘야 소리를 내보냅니다.)

4. 사운드 명령어 리스트
채팅창에 아래를 입력해 보세요!

!유부녀, !노래, !타코야키 : 각 사운드 재생

!개소리 또는 !왈왈 : 왈왈! 소리 재생
